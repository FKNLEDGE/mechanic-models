## 第一大块:AI × 模型 —— "老师傅"和"新徒弟"

### 0. 先认识两个角色

过程模型(DNDC、RothC、作物模型)和机器学习(神经网络),性格完全相反:

| | **过程模型(老师傅)** | **机器学习/AI(新徒弟)** |
|---|---|---|
| 怎么干活 | 靠科学原理一步步推 | 靠看海量例子"找规律" |
| 优点 | 懂道理、能解释、**没见过的情况也能合理外推** | 记性超强、模式识别极快、能抓住人没想到的关系 |
| 缺点 | 某些公式可能有死角(算不准);跑起来慢 | **不懂原理、容易在没见过的情况下瞎说**;要喂很多数据 |

一句话:**老师傅讲道理但偶有死角,新徒弟反应快但不讲道理。** 把两人搭配起来,就是当下最热的"混合建模(hybrid modeling)"。下面三种搭配,从易到难。

### 1. 搭配一:代理模型(emulator)—— 让徒弟"模仿"老师傅,图个快

**痛点**:老师傅干活慢。如果你要跑一万次(比如第二部分的不确定性分析、给区域每个网格都跑),慢得受不了。

**做法**:让聪明的徒弟在旁边看老师傅干很多遍,记住"什么输入 → 什么输出",学会之后,**徒弟能秒答**,不用再请老师傅。这个"模仿者"就叫**代理模型 / 仿真器(emulator / surrogate model)**。

- 徒弟学的是"输入→输出"的映射,**不是真原理**。
- 常用神经网络或**高斯过程(Gaussian Process, GP)**当徒弟。GP 的好处:它回答时还会附上"我有多确定"(给出误差范围),特别适合做不确定性分析。
- **用途**:把又慢又昂贵的模型"提速",让原本跑不动的几万次敏感性分析、校准、大尺度模拟变得可行。

**回报最高、最容易上手**,建议从这个开始。

### 2. 搭配二:残差学习(residual modeling)—— 徒弟专门学"老师傅哪儿算偏了"

**痛点**:老师傅算个大概,但总在某些情况下系统性地偏高或偏低。

**做法**:让老师傅照常算,徒弟**专门盯着"老师傅算的 − 实测"这个差(残差)**,学会预测这个偏差,最后补上:

```
最终结果 = 老师傅算的 + 徒弟预测的偏差
```

- 好处:**保留了老师傅的全部道理和可解释性**,徒弟只负责"擦屁股"补结构缺陷。
- 比纯 AI 更可信,因为主体仍是讲道理的机理模型。

### 3. 搭配三:可微分建模(differentiable modeling)—— 把某个不靠谱的小步骤交给徒弟,整体一起练

**痛点**:老师傅某个具体小步骤不靠谱(比如第一部分的水分调光器 f(W),在极端暴雨下算不准)。

**做法**:把这个小步骤**单独换成徒弟来做**,但整条流水线还是老师傅的骨架(浴缸、水管、积分循环都不变),然后**端到端一起训练**——让徒弟在"嵌在老师傅体内"的状态下学到最优。

- 实现上要把整个模型用支持"自动求导(automatic differentiation)"的工具(PyTorch / JAX)重写,这样才能算出"输出对每个参数的梯度",用梯度下降把嵌进去的徒弟练好。
- **Neural ODE**(把第一部分的 `dC/dt = ...` 右边那一坨直接用神经网络表示)就是这种思路的极端形式。
- 这是三种里最难的,通常最后才上。

### 4. 怎么"管教"徒弟:别只要答案对,还要不许违反物理(PINN / KGML)

新徒弟最大的毛病是"为了答案对,不惜违反常识"(比如算出碳凭空多出来)。所以训练时除了要求"贴近实测",还**额外要求它不许违反物理定律**(质量守恒、能量守恒),把这条要求写进训练的"扣分项"里。

- 这类方法叫**物理信息神经网络(PINN, Physics-Informed Neural Network)** 和**知识引导机器学习(KGML, Knowledge-Guided Machine Learning)**。
- 直白说:训练徒弟时,答错扣分,**违反物理也扣分**——逼它既准又守规矩。

### 5. 真实战绩(给你信心)

- **KGML-ag**(估农田 N₂O 排放):先让"老师傅模型"(一个叫 ecosys 的高级过程模型)生成**海量练习题**把徒弟教出底子,再用真实田间观测微调。结果交叉验证 **r² = 0.81、RMSE = 3.6 毫克氮/平方米/天**,稳定地比"纯老师傅"和"纯徒弟"都强。
- **可微分水文模型**(Feng 等 2022):把神经网络嵌进 HBV 水文模型骨架,在 671 个美国流域上中位评分(NSE)**0.732**,**逼近纯 AI(LSTM)的 0.748**——但它保留了物理可解释性,这是纯 AI 给不了的。

### 6. 三种怎么选 + 上手顺序

| 方式 | 可解释性 | 没见过的情况(外推) | 数据需求 |
|---|---|---|---|
| 残差 / 可微分(留骨架) | 高 | 稳 | 中 |
| 代理模型 | 中 | 中 | 中 |
| 纯 AI(不留骨架) | 低 | **易翻车** | 最贪 |

**上手顺序建议**:先做**代理模型**(给现成模型提速,风险最低、回报最高)→ 再做**残差学习** → 最后才碰**可微分**。一个农学生完全可以从"用 GP 模仿自己的 RothC"起步。

## 第二大块:临界点/突变 —— 为什么系统会突然"翻车"

这是你最早就关心的话题。现在用最直观的方式讲透。

### 7. 先理解"稳定"和"不稳定":小球在山谷里

把系统的状态想象成**一个小球**,它待在某个地形里:

```
   稳定(山谷底)              不稳定(山顶)
        ╲   ╱                      ╱╲
         ╲ ╱                      ╱  ╲
          ●   ← 推一下会滚回来       ╲● → 推一下就滚走
```

- **稳定状态(吸引子 / attractor)** = 小球在**山谷底**。推它一下,它会自己滚回谷底。土壤碳的平衡、健康的生态系统,都是这种"谷底"。
- **不稳定状态** = 小球在**山顶**。轻轻一碰就滚走,永远停不住。
- 一片地形里可能有**好几个山谷**(好几个稳态),小球落在哪个谷,取决于初始位置——这就是第一、二部分提过的"初值敏感"和 spin-up 为什么重要。

（如果你想看一眼数学:一维系统 `dx/dt = f(x)`,平衡点就是 `f(x)=0` 的地方;判断稳不稳定看那点的斜率 `f'`,斜率为负=谷底=稳定,为正=山顶=不稳定。不记也没关系,记住"山谷/山顶"这张图就够。）

### 8. 突变到底是什么:山谷被填平,小球被迫滚走

现在关键来了。如果你**慢慢改变某个外部条件**(比如持续升温、持续加营养盐),地形本身会**慢慢变形**。某一刻,小球所在的那个山谷**突然变平、消失了**——小球只能"哗"地滚到远处另一个山谷。

**这一瞬间的剧变,就是"临界点 / 突变(tipping point)"。** 数学上最经典的一种叫**鞍结分岔(saddle-node / fold bifurcation)**:一个稳定谷和一个不稳定坡碰到一起、同时湮灭,系统被迫跳到另一个状态。

- 正规形(看一眼即可):`dx/dt = r − x²`。当参数 `r` 越过 0,平衡点突然消失,系统骤变。
- 还有几种"地形变形"的方式:**跨临界**(两个状态交换稳定性)、**叉式**(一个谷分裂成俩)、**Hopf**(谷变成一圈,系统开始周期振荡)。名字知道即可。

### 9. 翻过去容易,翻回来难:多稳态 + 迟滞(湖水变浑)

最反直觉、也最重要的一点:**很多突变是"单行道"**。

经典例子是 **Scheffer 的浅湖模型**:一个湖有两个稳态——**清水**(水草主导,鱼虾健康)和**浊水**(藻类暴发,水体浑浊)。
- 你慢慢往湖里加营养盐(化肥流失),清水态能撑一阵,但到某个临界点,湖**突然从清变浑**。
- 你以为"那我把营养盐降回去不就清了?"——**不行!** 降回原来的水平,湖还是浑的。你得把营养盐降到**比原来低得多**的程度,湖才肯变清。

这种"去的阈值和回来的阈值不一样、回来更难"的现象,叫**迟滞(hysteresis)**,对应的两个稳态叫**替代稳态(alternative stable states)**。草地荒漠化、土壤退化,都有这个特征。**寓意:别等系统翻车了才后悔,因为翻回来的代价可能高得多。**

### 10. 怎么提前知道"要出事了":临界慢化 + 早期预警信号

好消息:系统在**快翻船之前,会发出信号**。

直觉:一艘船快翻的时候,你扶正它会越来越**费劲**,而且它晃一下要**晃很久**才停。系统接近临界点时也一样——受到扰动后**恢复得越来越慢**,这叫**临界慢化(critical slowing down)**。

从数据(比如逐年的土壤碳、N₂O 时间序列)里能量出三个**早期预警信号(early-warning signals)**:
- **滞后-1 自相关上升**:晃一下要晃很久才停(系统"记性"变长)。
- **方差(波动幅度)上升**:晃得越来越大。
- **闪烁(flickering)**:开始在两个状态之间来回横跳。

量这些信号其实就几行代码(滚动窗口算方差和自相关):

```python
import numpy as np
from statsmodels.tsa.stattools import acf

def early_warning(x, win=50):
    """x 是时间序列;返回滚动方差和滚动自相关"""
    var, ar1 = [], []
    for i in range(len(x) - win):
        seg = x[i:i+win]
        # 先去掉长期趋势,只看波动
        seg = seg - np.polyval(np.polyfit(np.arange(win), seg, 1), np.arange(win))
        var.append(np.var(seg))                 # 波动幅度
        ar1.append(acf(seg, nlags=1, fft=False)[1])  # 滞后-1自相关
    return np.array(var), np.array(ar1)
```
如果跑出来这两条线都**随时间往上爬**,就是"快出事了"的预警。(这套方法的奠基文献是 Scheffer 等 2009 年发在 *Nature* 上的综述。)

### 11. 农业模型里的真实突变(不是 bug,是真现象)

回到你的领域,这些突变真实存在:
- **DNDC 的 N₂O 脉冲**:一场大雨让土壤淹水缺氧,氧化还原电位(Eh)**跌破约 500 毫伏**,反硝化突然启动;继续跌破 **−150 毫伏**,产甲烷又启动。于是淹水后一两天内 N₂O/CH₄ 通量爆发式上升——这是阈值切换式的突变。
- **土壤碳崩塌**:某些管理/土地利用变化下,土壤碳存在多个稳态。有研究(Clayton 等 2021)在一条复垦序列里发现,土壤有机碳在 **1%** 这个临界值附近,微生物群落特征发生突变。
- **作物物候跳变**:积温攒到阈值就换发育阶段(第一部分讲过),会让产量对播期/温度的响应出现"悬崖"。

### 12. 最重要的一课:怎么分辨"真突变"和"代码 bug"?

当模型跑出一条诡异的骤降曲线,程序员的第一反应是"代码出 bug 了",而一个懂行的农学生应该冷静做**三步判别**:

1. **它对应一个物理阈值吗?**(比如 Eh 跌破 500 mV、底物耗尽)—— 有物理对应,像真突变。
2. **把时间步长减半,突变还在原来的位置、原来的幅度吗?**(第二部分的"收敛测试")—— 如果减半后突变漂移或消失,那是**数值毛病**,不是真现象。
3. **质量守恒吗?**(第二部分的查账机器)—— 如果碳凭空多了/少了,那是 bug。

**三个都满足,才是真实的 regime shift;否则就是数值伪迹。**

还有一条铁律帮你快速判断:**线性库模型(像 RothC)在数学上只有唯一一个稳态,不可能自发出现多个稳态或突变**。所以如果你的纯线性模型跑出了多稳态/突变,**那一定是 bug**;只有当模型里含有非线性(米氏饱和、乘性因子、阈值开关、微生物反馈)时,多稳态才可能是真的。

> 提醒:早期预警信号**不是万能的**。在变化非常快或强非线性的情况下,这些信号可能不出现;方差上升也可能只是因为外部强迫本身在变剧烈,而非真的临界慢化。它是"概率性提示",不是"确定性预言"。

## 13. 小结 & 第四部分预告

这一部分你拿到了:
1. AI × 模型的三种搭配——**代理模型(模仿提速)、残差学习(补偏差)、可微分(换掉烂步骤端到端练)**,以及怎么用物理定律"管教"徒弟(PINN/KGML);上手顺序:代理 → 残差 → 可微分;
2. 突变的本质——小球所在的**山谷被填平,被迫滚到另一个谷**(鞍结分岔);多稳态 + 迟滞 = **翻过去容易翻回来难**(湖水变浑);
3. 提前预警靠**临界慢化**(恢复变慢)→ 自相关上升、方差上升、闪烁;
4. 分辨真突变 vs bug 的**三步判别**(物理阈值 + 步长收敛 + 守恒),以及"线性模型不会自发多稳态"这条铁律。

**第四部分(最后一部分)预告**——说"继续"我就写:
**从一个想法到一篇能发表、且别人能复现的论文的完整流程**:怎么找到值得研究的缺口、数据怎么准备、校准和验证的严格规矩(为什么不能拿同一批数据又调又验)、怎么把点上的模型推到整个区域、怎么把卫星数据"喂"进模型、最后怎么发表、怎么让别人下载你的代码就能重跑出你的结果。会用一个贯穿全程的例子("改进 DNDC 的水分函数算 N₂O")把这条链串起来。
