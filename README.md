---

## 这份指南是给谁的、要解决什么

如果你是农学 / 生态背景，会用模型却把它当"黑箱"——数据丢进去、结果吐出来，不知道里面在算什么——这份指南就是带你**把黑箱拆开**，看清三件事并最终自己动手：

1. 模型用什么**公式**描述土壤、作物、水和气体；
2. 计算机怎么把这些公式**算出来**；
3. 这堆公式怎么变成能跑的**软件**，以及怎么**校准参数、量化不确定性、做成一篇可复现的论文**。

默认你**没有**数学或编程基础。每个概念都先打比方（浴缸水管、收音机旋钮、老师傅带徒弟、翻船、做一道能进菜谱的菜），再给能跟着算的小例子，最后才出现公式。

## 7 个思维框架（贯穿所有模型的"骨架"）

不管模型叫什么名字，看穿它们靠这 7 副骨架（详见 [学习地图总纲](02_课程学习地图/00_学习地图总纲_20模型7框架.md)）：

1. **状态变量 + 通量**（守恒律 / "浴缸"模型）——今天的量 = 昨天的量 + 进 − 出。
2. **多重限制因子**（潜在 × 胁迫，`潜在速率 · f(T)·f(W)·f(N)`）——先算理想上限，再用 0–1 折扣往下打。
3. **速率 - 状态 - 更新**（ODE 离散化 / 显式 Euler）——一天一天往前"挪"，不是解方程。
4. **尺度层级**（点 → 田 → 区域 → 全球）——小尺度成立的关系，大尺度未必成立。
5. **动力系统稳定性**（平衡、反馈、分岔、迟滞）——为什么系统会突然"翻车"。
6. **校准 - 验证 - 不确定性**（正/反问题、equifinality、Bayesian/GLUE）——给概率范围，不给假精确的单点。
7. **机理 vs 经验 vs 混合**（可解释性 - 精度权衡）——什么时候用道理、什么时候用数据、什么时候融合。

## 实操包快速开始

```bash
cd 03_动手实操包
python3 -m venv venv && source venv/bin/activate     # Windows: venv\Scripts\activate
pip install numpy scipy pandas scikit-learn matplotlib
pip install pcse          # Lab 2 的 WOFOST 用
pip install SALib         # Lab 4 的 Sobol 敏感性分析用

python3 lab1_rothc_unittest.py        # 先跑这个：有标准答案，建立信心
```

Lab 1 应当复现 Rothamsted 官方四个数（DPM 0.1140 / RPM 4.4455 / BIO 0.6542 / HUM 25.8423）。
四个 lab 的预期输出和"换成你自己数据"的方法都在 [`03_动手实操包/README.md`](03_动手实操包/README.md)。
