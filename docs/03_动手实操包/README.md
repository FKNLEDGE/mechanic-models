## Lab 3 · 残差混合 + 外推 + equifinality（Round 6 能力落地）

```bash
python3 lab3_residual_hybrid.py
```

**这一关教你：** 机理 vs 经验 vs 混合（框架⑦）+ 标定/不确定性（框架⑥）三件事，全在一个脚本里。

**预期输出（三方对比，混合最优）：**

```
纯机理 (process-only) ≈ 0.82 t/ha (RMSE)
纯 ML  (RF on yield)  ≈ 0.43
残差混合 (hybrid)     ≈ 0.38   ← 最低：RF 补上了机理模型漏掉的 rain×N 交互
```
还会演示：**外推时纯 ML 卡死**（N=250→400 预测几乎不变），而混合靠机理项给出"过量减产"，外推可信；以及 **equifinality**（多组不同 (k,C0) 拟合一样好）。

**换成你自己的数据（一行切换）：** 准备一个含 `temp, rain, Nrate, yield` 列的 CSV，把 `main()` 里的 `make_dataset()` 换成 `load_your_csv('your.csv')` 即可。

## Lab 4 · 标定 + 敏感性 + 不确定性（从"会跑模型"到"会做科研"）

```bash
python3 lab4_calibration_sensitivity_uncertainty.py
```

**这一关教你（框架⑥的完整落地）：** 把 Lab 1 的 RothC 当被研究对象，走一遍真正的科研工作流——先做敏感性分析搞清"哪些参数才值得调"，再标定，再用 GLUE 量化不确定性，最后用 GP 仿真器加速。

**预期输出（四个部分）：**

```
A) Sobol 敏感性 : input(S1≈0.60) 与 abc(≈0.28) 主导稳态 SOC；clay 次要、ratio 可忽略（已固定 seed，可复现）
B) 标定         : 拟合得 input≈2.49, abc≈0.272（真值 2.50 / 0.280）—— 反推成功
C) GLUE         : 150 组'行为合格'参数，input∈[2.1,3.4]、abc∈[0.20,0.50] 都拟合得一样好
                  → equifinality；情景(碳输入+20%)的 SOC 增量给出 5–95% 区间，而非单点
D) GP 仿真器    : 用 30 次真模型训练'快替身'，预测与真模型吻合，可毫秒级评估上万次
```

**这是整套实操包里最重要的一关**：它就是"用农学做灵魂"——会跑模型只是入门，**会标定、会诚实给出不确定性区间，才是做研究**。

**换成你自己的模型/数据：** 把 `rothc_soc()` 换成你的模型（或 Lab 2 的 WOFOST 输出），把 `_make_observations()` 换成你的实测序列即可。

## 等你有了自己的研究抓手：一页纸方案模板

你现在没有具体数据，所以先用上面公开数据练手。等你拿到一篇要复现的论文或一个数据集，按这张模板把"该用机理/数据/混合"想清楚再动手：

1. **目标变量是什么？** （产量 / N₂O / 土壤碳 / 蒸散…）
2. **你要外推吗？** 要预测没观测过的气候/管理 → 偏机理或混合；只在分布内预测 → 可纯 ML。
3. **数据有多少、多脏？** 多且干净 → ML 可行；少 → 机理或"机理生成合成数据预训练"的混合。
4. **选骨架模型：** 土壤碳→RothC/CENTURY/MIMICS；作物→WOFOST/DSSAT/APSIM；痕量气体→DNDC/DAYCENT；水文→SWAT/TOPMODEL/HYDRUS。
5. **标定与验证怎么分？** split-sample / 留出年份或站点；先做敏感性分析挑要调的参数。
6. **怎么报告不确定性？** 集合 / quantile RF / GP / Bayesian——别只给单点预测。
7. **要不要混合？** 骨架可信但某子过程薄弱（如某个胁迫函数）→ 残差校正或可微替换。

把这七问填完，你就有了一个可执行的研究计划——直接拿来找我，我们就从公开数据切换到你的真问题。
