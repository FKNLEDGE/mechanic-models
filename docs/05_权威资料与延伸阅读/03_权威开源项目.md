## ⭐ 先学会"挑项目"：怎么判断一个开源项目值不值得学（小白必看）

面对一堆 GitHub 仓库别发懵，按这 6 个信号花 1 分钟体检一遍，能避开 90% 的坑：

| 信号 | 在哪看 | 怎么判断 |
|---|---|---|
| **① 谁在维护** | 仓库名/About/README | 大学、国家机构（USDA、NCAR、INRAE、FAO）、知名社区(NumFOCUS) > 论文配套 > 个人练手 |
| **② 最近提交** | 仓库首页右侧 "last commit" / commits | 一年内有提交 = 活；多年没动 = 可能弃坑（除非是稳定的经典工具） |
| **③ 文档 & 示例** | README、readthedocs、`examples/` 或 `notebooks/` 文件夹 | 有"快速上手"+ 可运行 Notebook 才适合小白；**没文档的项目，再强也先别碰** |
| **④ Stars / 关注** | 仓库首页 ★ 数 | star 多≠一定好，但 star 高通常说明社区在用、有人踩过坑；< 10 star 且非官方要谨慎 |
| **⑤ 测试 & CI** | `tests/` 文件夹、绿色 ✓ 徽章 | 有自动测试 = 作者在乎"算得对"，结果更可信 |
| **⑥ License** | 仓库首页右侧 / `LICENSE` 文件 | 有 MIT/GPL/Apache/BSD 才能放心用；**没 license = 默认"保留所有权利"，不可自由使用** |

> **小白口诀**：先看①机构背书 + ④star 筛"权威"，再看②last commit 看"死活"，最后看③README/Notebook 看"我能不能上手"。三关都过，再投入时间。

## 二、用数据的工具栈（把 ERA5 / MODIS / NetCDF 读进来、画出来）

📌 在 [02](02_公开数据集与可复现工具.md) 下载了 NetCDF/GeoTIFF 却"读不进来、画不出图"？卡点就靠这一栈解决。

| 工具 | 维护方 | ★ / 活跃度 | 一句话点评 |
|---|---|---|---|
| 🥇 [xarray](https://github.com/pydata/xarray) | PyData / NumFOCUS | ★4.2k / 活跃 | 带坐标标签(lat/lon/time)的多维数组核心引擎，`xr.open_dataset()` 一行读 ERA5/MODIS/CMIP6，**地学 Python 一切的起点** |
| [rioxarray](https://github.com/corteva/rioxarray) | Corteva | ★0.6k / 活跃 | xarray 的地理空间扩展，一行做 CRS 变换/裁剪/重采样，遥感栅格首选桥梁 |
| [rasterio](https://github.com/rasterio/rasterio) | 社区(原 Mapbox) | ★2.5k / 活跃 | 基于 GDAL 的栅格读写，比 GDAL 命令行友好；rioxarray 的底层 |
| [netCDF4-python](https://github.com/Unidata/netcdf4-python) | Unidata (UCAR) | ★0.8k / 活跃 | NetCDF 官方 Python 接口，要直接操控变量属性/压缩/写文件时用 |
| [dask](https://github.com/dask/dask) | Dask / NumFOCUS | ★13.8k / 活跃 | xarray 的并行后端，几十年 ERA5 在笔记本上也能分块"懒加载"，不爆内存 |
| [Cartopy](https://github.com/SciTools/cartopy) | Met Office / SciTools | ★1.6k / 活跃 | 地图投影 + matplotlib 制图，给数据加海岸线/国界，画空间分布图标准件 |

> **GDAL** 是上面 rasterio/rioxarray 的底层依赖，小白无需直接写 GDAL，`conda install rasterio` 会自动带上。
