## 🆘 卡住了怎么办（决策树）

- **装不上 / 报错** → 去 [安装与常见报错](安装与常见报错.md)，对症的 8 条基本覆盖。
- **看到不认识的词** → [术语表](术语表.md) 搜一下。
- **看到看不懂的符号（dC/dt、特征值…）** → [数学补给站](数学补给站.md)。
- **某一段读三遍还懵** → **先跳过往下读**，常常后面的例子会让它"回过味来"；或直接去跑对应的练习脚本，看着数字反推概念。
- **代码跑出来数字不对** → 用教程第2部分的三个自检（守恒 / 步长收敛 / 负值）定位；把完整报错贴出来。
- **整体不知从哪下手** → 回最上面走"一个周末最短路径"。
