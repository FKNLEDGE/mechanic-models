# 安装与常见报错 · 别在"还没开始"就被劝退

> 跑代码卡住是新手最容易放弃的地方。这一页给你**一键安装**步骤 + **最常见 8 个报错**的对症解法。
> 看到红色报错先别慌——99% 是下面这几种之一。

---

## 一、一键安装（一次性，5 分钟）

```bash
# 1) 建一个干净的虚拟环境（强烈建议，避免污染系统 Python）
python3 -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate

# 2) 一键装全部依赖
pip install -r requirements.txt
```

- 没有 `requirements.txt`？它在**仓库根目录**。或手动：`pip install numpy scipy pandas scikit-learn matplotlib SALib pcse`。
- Python 用 **3.9 或更新**（`python3 --version` 查一下）。
- `Lab 1 / Lab 3 / Lab 4` 和 6 个 Round 练习**纯本地离线**可跑；只有 **Lab 2** 首次运行需要联网。

跑通第一个：
```bash
cd docs/03_动手实操包
python3 lab1_rothc_unittest.py      # 应打印 RothC 官方四个数
```

## 二、最常见的 8 个报错（对症下药）

### 1. `ModuleNotFoundError: No module named 'numpy'`（或 scipy/sklearn/SALib/pcse）
**原因**：没装包，或装到了另一个 Python 里。
**解法**：`pip install -r requirements.txt`。若还报错，确认 `pip` 和 `python3` 是同一个环境：
```bash
python3 -m pip install -r requirements.txt    # 用 python3 -m pip 最稳
```

### 2. Windows 上中文/✅ 变成乱码，或 `UnicodeEncodeError: 'gbk' codec ...`
**原因**：脚本里有中文和 `✅` emoji，Windows 自带控制台默认不是 UTF-8。**这不是你代码错了。**
**解法**（任选其一）：
```bat
set PYTHONUTF8=1            &  python3 lab1_rothc_unittest.py     :: 临时
chcp 65001                                                       :: 把控制台切到 UTF-8
```
或用 **PowerShell / Windows Terminal / VS Code 集成终端**（它们默认 UTF-8，不会乱码）。

### 3. Lab 1 显示 `DPM 0.1139 / 官方 0.1140` 却打 ✅，是 bug 吗？
**不是。** DPM 精确值是 0.11394，4 位小数显示成 0.1139；官方表里的 0.1140 是它自己的取整。其余三库 4 位完全一致。脚本里已有透明说明行。**放心，你的代码是对的。**

### 4. Lab 2 卡住 / `ConnectionError` / `URLError` / 取气象超时
**原因**：Lab 2 首次运行要联网下载作物参数 + 取 NASA POWER 气象。公司/学校网络或无网时会失败。
**解法**：
- 换个能联外网的网络重试（NASA POWER 偶尔慢，多等或重跑一次）。
- **暂时不联网也想学作物模型？** 跑离线版：`docs/02_课程学习地图/exercises/round3_exercise.py`——同一套"GDD→截光→RUE→水分胁迫"，纯本地、看得到 de Wit 产量差。

### 5. Lab 2 的产量数字和 README 写的 7982/6790 对不上一点点
**正常。** Lab 2 用的是 NASA POWER **实时**公开气象，数据会随时间微更新，所以数字会轻微浮动（README 已用"≈/示例"标注）。趋势（潜在 > 水分限制）不变即可。

### 6. 跑出图了吗？`matplotlib` 不弹窗 / 没看到图
**原因**：很多脚本默认把图**存成 PNG 文件**而不弹窗（服务器/无显示环境更稳）。
**解法**：去脚本所在目录找 `*.png` 文件（如 `lab1_rothc_spinup.png`）。想交互弹窗，本地装好 matplotlib 后把脚本里的 `matplotlib.use("Agg")` 注释掉即可。

### 7. `pip install pcse` 失败 / 编译报错
**解法**：先升级 pip：`python3 -m pip install --upgrade pip`，再装。仍失败多半是网络问题，换网重试。`pcse` 只有 Lab 2 用，不影响其它 lab。

### 8. `command not found: python3` / `pip`
**原因**：没装 Python，或命令名不同。
**解法**：装 [Anaconda](https://www.anaconda.com/)（自带 Python + 全部科学库，最省事），或从 [python.org](https://www.python.org/) 装。Windows 上命令可能是 `python` 而非 `python3`。

## 三、读报错的 3 个小技巧

1. **从最后一行往上看**——`Error` 那行通常直接说了是什么错（如 `ModuleNotFoundError`）。
2. **倒数第二段**会指出**哪个文件第几行**出的问题，照着去看那一行。
3. 把**完整报错**（不是截一半）连同你跑的命令一起贴出来——给我也行，给搜索引擎也行，基本都能秒定位。
