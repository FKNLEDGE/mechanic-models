## 0. 先建立一个总观念

整份教程的数学，**只为回答一件事**：

> **"已知现在的状态，怎么算出下一刻的状态？"**

所有看起来吓人的符号，都是这句话的不同写法。记住这点，下面全是细节。

---

## 1. 变量、函数、下标——读公式的"字"

- **变量**：会变的量，用字母代表。`C` = 碳量，`T` = 温度，`t` = 时间。
- **函数 `f(T)`**：一台小机器，喂进去 `T`，吐出来一个数。`f(T)` 读作"`f` 在 `T` 处的值"。教程里的"温度调光器 f(T)"就是：喂温度、吐一个 0~1 的折扣。
- **下标**：给同名变量编号区分。`k_DPM`、`k_HUM` 就是"DPM 那个 k"和"HUM 那个 k"，不是相乘。
- **Σ（求和）**：`Σ` 是希腊字母 Sigma，意思是"把后面一串加起来"。`Σ(截获PAR × LUE)` = "每天的(截光×效率)全加起来"。就是一个"累加"。

> 一句话：公式里的字母只是"给量起名字"，下标是"编号"，函数是"喂进吐出的小机器"。

---

## 2. `dC/dt`——这份教程最核心的符号（导数）

你会无数次见到 `dC/dt`。它**不是除法**，整体读作"C 随时间 t 的变化速度"。

**大白话**：就是浴缸**水位上升/下降的快慢**。

- 水龙头开大、下水道堵住 → 水位涨得快 → `dC/dt` 是个大正数。
- 下水道开大、不进水 → 水位降 → `dC/dt` 是负数。
- 进出相等 → 水位不动 → `dC/dt = 0`（这就是"平衡/稳态"）。

所以教程里那个吓人的核心方程：

```
dC/dt = 进水 − 出水 = Input − k·C·f(T)·f(W)
```

翻译成人话就是：**"碳变化的快慢 = 流进来的 − 流出去的"**。仅此而已。

> 你**不需要**会"求导"。你只需要知道：`dC/dt` 是个"速度"，模型每一步先算出这个速度，再用它往前挪一小步。

## 3. `e` 和 `exp`——指数，描述"按比例增减"

`e ≈ 2.718`，是个固定的数（像 π≈3.14 一样）。`exp(x)` 就是 `e` 的 `x` 次方，写作 `e^x`。

**为什么生态模型离不开它？** 因为自然界大量过程是"**按现有量的固定比例**增减"的：

- 钱按利率涨 → 越涨越快（`e` 的正指数）。
- 碳按速率衰减 → 越少减得越慢（`e` 的负指数），像手机电量越低掉得越慢。

教程里一阶衰减的精确解：

```
C(t) = C₀ · e^(−k·t)
```

**怎么读**：`C₀` 是初始量，`e^(−k·t)` 是"过了时间 t 之后还剩的比例"。

- `k·t` 越大 → `e^(−k·t)` 越接近 0 → 剩得越少。
- 一个有用的口算：`e^(−1) ≈ 0.37`。所以当 `k·t = 1`（即 `t = 1/k`）时，还剩约 37%——这个 `1/k` 就叫**周转时间**。
- RothC 手算里 `0.1533 × e^(−0.297) = 0.1533 × 0.743 = 0.1140`，那个 `0.743` 就是"这个月还剩 74.3%"。

> 记三个数就够用：`e^0=1`（没衰减）、`e^(−1)≈0.37`（剩三分之一多）、`e^(−大数)≈0`（基本没了）。

## 4. 积分 / "一步步往前挪"——计算机怎么真的算出来

数学课上的"积分"听着可怕，但在这份教程里它就是一件事：**把无数个小步加起来**。

模型不会解方程，它**走楼梯**（教程第一部分讲过）：

```
明天的碳 = 今天的碳 + (今天的变化速度 dC/dt) × (一小步 Δt)
```

把这个"加一小步"重复几百万次，就"积分"出了整条曲线。这就是**显式欧拉法**，也是"积分"在这里的全部含义。

- `Δt`（读"delta t"）= 一步的时间长度（一天、一个月、一小时）。`Δ` 就是"一小段变化"。
- 步子太大会出错（算出负的碳），所以一般用很小的 `Δt`。

> 你不需要会"积分技巧"。你只需要知道：**积分 = 把"速度 × 小步"累加起来**，而计算机最擅长重复加法。

## 5. 平衡点与稳定性——"小球在山谷"背后的数学

教程第三部分用"小球在山谷/山顶"讲稳定性。它的数学是这样的：

- **平衡点**：水位不动的地方，即 `dC/dt = 0`（进 = 出）。数学写成 `f(x*) = 0`，`x*` 读作"x 星"，指那个平衡值。
- **稳不稳**：看在平衡点附近，曲线的**斜率**是正是负。
  - 斜率为负 = 谷底 = **稳定**（推一下会滚回来）。
  - 斜率为正 = 山顶 = **不稳定**（推一下滚走）。

斜率就是第 2 节的导数。所以"判断稳定性"= "看平衡点处那个速度变化的方向"。

## 6. 特征值、Jacobian——Round 5 唯一"新"的硬词（只需直觉）

Round 5 会出现 **Jacobian** 和**特征值（eigenvalue）**。听着像天书，其实是第 5 节那个"斜率"在**多个变量**时的版本。

- 一个变量（只有碳）：稳不稳看**一个斜率**的正负。
- 多个变量（碳 + 微生物 + 氮一起变）：没法只用一个斜率，要用一张**斜率表**（每个变量对每个变量的影响），这张表就叫 **Jacobian 矩阵**。
- 这张表里藏着几个关键数字，叫**特征值**。判据和单变量一模一样：
  - **所有特征值的实部都 < 0 → 系统稳定**（受扰动会自己回来）。
  - **有一个 > 0 → 不稳定**（会被推离）。
- **临界点（分岔）**就是某个特征值**穿过 0** 的那一刻——稳定性翻转，系统"翻车"。

> 你不需要会算特征值（有现成函数 `numpy.linalg.eig`）。你只需要记住：**特征值是"多变量版的斜率"，全负就稳，冒出一个正的就要出事。**

## 7. 概率、分布、分位数——为什么"给范围"比"给单点"诚实

教程反复强调"别给一个数，要给范围"（贝叶斯、GLUE、不确定性）。背后的数学概念也很浅：

- **概率分布**：不是说"k = 10.2"，而是说"k 大概在 10 附近，离得越远越不可能"——画出来是一座小山（中间高两边低）。
- **分位数**：把可能值从小到大排好，"5% 分位"就是"只有 5% 的可能比它小"。报告 **"5%–95% 区间"** = "我有 90% 把握，真值落在这两个数之间"。
- 这就是为什么 Lab 4 给的是 `[10.55, 11.85]` 这样一个**区间**，而不是一个假装精确的单点。

## 8. 一张"符号→人话"对照表（撕下来贴电脑边）

| 符号 | 读作 | 人话 |
|---|---|---|
| `dC/dt` | C 对 t 的导数 | 碳量变化的**快慢**（浴缸水位升降速度） |
| `Δt` | delta t | 往前挪的**一小步**时间 |
| `f(T)` | f 在 T 处 | 喂温度、吐折扣的**小机器** |
| `k·C` | — | 出水速度 ∝ 现有量 |
| `e^(−kt)` | e 的 −kt 次方 | 过了时间 t **还剩的比例** |
| `Σ` | 求和 | 把一串数**加起来** |
| `∂` | 偏导 | 多个变量时，**只动一个**看影响 |
| `x*` | x 星 | **平衡值**（dC/dt=0 处） |
| 特征值 | eigenvalue | **多变量版的斜率**，全负=稳 |
| `p(θ\|D)` | 后验概率 | 看了数据后，参数**最可能在哪** |
| `[5%, 95%]` | 分位区间 | **90% 把握**真值落在这区间 |
