## A. 模型骨架与数值方法

| 术语 | 一句话 | 在哪学 |
|---|---|---|
| 状态变量 (state variable) | 我们关心、会随时间变的量（土壤碳、水、生物量）= 浴缸里的水 | 教程 1 |
| 通量 (flux) | 让状态变量增减的"水流"（落叶进、CO₂ 出） | 教程 1 |
| 质量守恒 (mass conservation) | 铁律：今天的量 = 昨天 + 进 − 出，碳不会凭空消失 | 教程 1 |
| 一阶衰减 (first-order decay) | 出水速度 ∝ 现有量，越多减得越快 `dC/dt=−kC` | 教程 1 |
| 速率常数 k (rate constant) | "水管粗细"，越大分解越快 | 教程 1 |
| 周转时间 (turnover time) | ≈ 1/k，这个库"换一遍"大概要多久 | 教程 1 |
| 乘性限制因子 | 实际速率 = 潜在 × f(T)×f(W)×…，任一因子=0 就停 | 教程 1 |
| 显式欧拉法 (explicit Euler) | "走楼梯"：明天 = 今天 + 速度×一小步，不解方程 | 教程 1 |
| 算子分裂 (operator splitting) | 快过程小步、慢过程大步，分开算（大火快炒 vs 小火慢炖） | 教程 1 |
| spin-up（预热） | 慢库要先空跑几百~上万年到稳态，再开始正式模拟 | Round 1 / Lab 1 |
| CFL 条件 | 解扩散方程时步长上限 `Δt≤Δz²/2D`，超了就乱抖发散 | 教程 2 |

## B. 土壤碳 / 生物地球化学

| 硝化 / 反硝化 | 铵→硝酸盐（需氧）/ 硝酸盐→氮气(含 N₂O)（缺氧） | Round 2 |

## C. 作物生长

| 术语 | 一句话 | 在哪学 |
|---|---|---|
| GDD（生长度日 / 积温） | 庄稼"攒热量"计时，攒够才换发育阶段，不看日历 | 教程 1 / Round 3 |
| Beer–Lambert 定律 | 光穿过冠层按指数衰减，叶越密截光越多 | 教程 1 / Round 3 |
| LAI（叶面积指数） | 叶子的"厚度"，越大截光越多 | 教程 1 |
| RUE / LUE（辐射/光能利用效率） | 截到的光按固定"兑换率"变干物质（≈1.4 g/MJ） | 教程 1 / Round 3 |
| PAR（光合有效辐射） | 太阳总辐射里庄稼能用的那约一半 | 教程 1 |
| SWFAC（水分胁迫因子） | 0~1 折扣 = 实际吸到的水 ÷ 想要的水 | 教程 1 |
| 倾倒水桶 (tipping-bucket) | 土壤分层当水桶，满了溢到下一层，简单稳 | 教程 1 / Round 4 |
| Richards 方程 | 物理化的土壤水流偏微分方程，准但慢、易发散 | Round 4 |
| de Wit 生产层级 | 潜在 → 水分限制 → 养分限制 → 实际产量，层层打折 | Round 3 / Lab 2 |
| HI（收获指数） | 产量 = 总生物量 × HI（多少比例长进籽粒） | Round 3 |
| Farquhar (FvCB) | 叶片光合 = min(Rubisco 限制, 光限制) − 呼吸 | Round 4 |

## D. 标定与不确定性

| 术语 | 一句话 | 在哪学 |
|---|---|---|
| 敏感性分析 | 先搞清"哪个参数旋钮最影响结果"，别瞎调全部 | 教程 2 / Lab 4 |
| Morris 法 | 便宜的粗筛，快速排除没用的旋钮 | 教程 2 / Round 6 |
| Sobol 法（S1 / ST） | 精确分账：S1=单独贡献，ST=含交互的总贡献 | 教程 2 / Lab 4 |
| 校准 / 验证 / 评价 | 调参 / 用独立数据检验 / 更全面的诊断——三者别混 | 教程 4 |
| 反问题 (inverse problem) | 从观测"反推"参数（正问题是参数→结果） | Lab 4 |
| RMSE | 模拟与实测平均差多少，越小越好 | 教程 2 |
| NSE（纳什效率） | =1 满分，=0 等于"还不如用平均值预测" | 教程 2 |
| KGE | 把相关性/偏差/变率分开打分；均值预测基准≈−0.41（非 0） | 教程 2 |
| 贝叶斯校准 | 不给唯一最优值，给参数的"概率分布" | 教程 2 |
| MCMC | 让计算机"随机游走"出那条概率曲线的采样办法 | 教程 2 |
| 先验 / 后验 | 调参前的常识 / 看了数据后更新的概率 | 教程 2 |
| equifinality（等效性 / 殊途同归） | 好几组不同参数都拟合得一样好 → 所以要给范围 | 教程 2 / Lab 3/4 |
| GLUE | 随机撒参数、留"拟合够好"的一批，得到不确定性区间 | Lab 4 |
| PEST / PEST++ | 不用改模型代码、套在外面自动调参的权威工具 | 教程 2 / 报告2 |

## F. 动力系统与临界转变

| 术语 | 一句话 | 在哪学 |
|---|---|---|
| 不动点 / 平衡点 | 系统不再变化的状态（`dC/dt=0`）= 小球停住的地方 | 教程 3 / Round 5 |
| Jacobian / 特征值 | "多变量版的斜率表"，特征值全负=稳，冒出正的=要翻 | Round 5 / [数学补给站](数学补给站.md) |
| 分岔 (bifurcation) | 慢慢改条件，平衡点突然出现/消失/变性 | 教程 3 / Round 5 |
| 鞍结 / fold 分岔 | 最经典的临界点：稳定谷与不稳定坡相撞湮灭 | 教程 3 / Round 5 |
| 迟滞 (hysteresis) | 翻过去容易翻回来难，去/回阈值不同（湖水变浑） | 教程 3 / Round 5 |
| 替代稳态 | 同一条件下系统可能稳在两个不同状态（清水/浊水） | 教程 3 / Round 5 |
| 临界慢化 | 接近临界点时，受扰动恢复越来越慢（船快翻晃得久） | 教程 3 / Round 5 |
| 早期预警信号 (EWS) | 自相关↑、方差↑、闪烁 → "快出事了"的概率性提示 | 教程 3 / Round 5 |
