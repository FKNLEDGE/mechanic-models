## 学习路径（难度严格递增）

```
Round 1 地基 ─→ Round 2 土壤生化 ─→ Round 3 作物 ─→ Round 4 水文/陆面 ─→ Round 5 动力系统 ─→ Round 6 数据/混合
守恒+Euler      多库+M-M酶动力学     光→产量         点→面+能量平衡        平衡/分岔/临界点      标定/不确定/混合
```

**一句话主线**：状态变量（库）+ 通量 → 守恒律写出 `dC/dt` → 潜在速率 × 胁迫因子 → 显式 Euler 逐日积分 → 标定 + 量化不确定性 → 升尺度 → 机理×ML 混合。

## 7 个思维框架（看穿所有模型的骨架）

| # | 框架 | 一句话 | 核心式 / 心智图 |
|---|---|---|---|
| ① | 状态变量 + 通量（守恒律） | 浴缸：今天 = 昨天 + 进 − 出 | `dC/dt = 进 − 出` |
| ② | 多重限制因子（潜在 × 胁迫） | 先算理想上限，再打 0–1 折扣 | `实际 = 潜在 · f(T)·f(W)·f(N)` |
| ③ | 速率 - 状态 - 更新（离散化） | 一天一天往前挪，不解方程 | `C(t+Δt)=C(t)+Δt·dC/dt` |
| ④ | 尺度层级（点→田→区→全球） | 小尺度的关系大尺度未必成立 | 聚合误差 / change-of-support |
| ⑤ | 动力系统稳定性 | 平衡、反馈、分岔、迟滞、临界点 | 不动点 `f(x*)=0`；稳定看 Jacobian 特征值 |
| ⑥ | 校准 - 验证 - 不确定性 | 给概率范围，不给假精确单点 | 反问题 + equifinality + Bayesian/GLUE |
| ⑦ | 机理 vs 经验 vs 混合 | 何时讲道理、何时用数据、何时融合 | `混合 = 机理 + ML(残差)` |

## 6 轮 · 20 模型 · 招牌方程

### Round 1 地基（守恒 + Euler）　难度：入门
| 模型 | 招牌机制 | 招牌式 |
|---|---|---|
| **Logistic** | 有限增长（S 形） | `dN/dt = r·N·(1 − N/K)` |
| **RothC** | 5 库一阶衰减 | `C(t+Δt)=C·exp(−a·b·c·k·Δt)`；k: DPM 10/RPM 0.3/BIO 0.66/HUM 0.02 |
| **AquaCrop** | 水分生产力驱动 | `生物量 B = WP · Σ(Tr/ET0)` |

### Round 2 土壤生物地球化学（多库 + 酶动力学）　难度：入门→高级
| 模型 | 招牌机制 | 招牌式 |
|---|---|---|
| **CENTURY** | active/slow/passive 三库 + 质地保护 | 一阶衰减 × 质地修正；C:N:P:S 耦合 |
| **DNDC** | 厌氧气球（Eh→厌氧体积比） | Nernst `Eh=E0+(RT/nF)ln([ox]/[red])`；双底物 M–M |
| **DAYCENT** | CENTURY 的日步版，抓 N₂O 脉冲 | 同 CENTURY，Δt=1 天捕捉降雨/冻融爆发 |
| **MIMICS** | 微生物显式（非线性） | `V = Vmax·S/(Km+S)`；r/K 功能群 + MAOM |

### Round 3 作物生长 / 产量（光 → 产量）　难度：入门→中级
| 模型 | 招牌机制 | 招牌式 |
|---|---|---|
| **WOFOST/SUCROS** | 冠层分层光合 / LUE | de Wit 层级：潜在→水分限制→养分限制 |
| **DSSAT** (CERES/CROPGRO) | 积温物候 + 碳分配 | `产量 = 生物量 × HI`，受胁迫折减 |
| **APSIM** | 模块化、以土壤为中心 | 每日 rate→integrate→update |
| **EPIC / STICS** | 侵蚀/水土 / 法式氮素 | 共享：`GDD`、`I=I₀e^(−k·LAI)`、`ΔDM=RUE·fPAR·PAR` |

**作物三件套**：`GDD=max((Tmax+Tmin)/2−Tbase,0)` ｜ `截光比例=1−e^(−k·LAI)` ｜ `ΔDM=RUE·截光·PAR·f(水/氮)`

### Round 4 水文 + 生态系统 / 陆面（点→面 + 能量）　难度：中→高
| 模型 | 招牌机制 | 招牌式 |
|---|---|---|
| **SWAT** | 半分布式 + HRU + 曲线数 | `Q=(P−0.2S)²/(P+0.8S)`，`S=25400/CN−254` |
| **TOPMODEL** | 地形湿度指数 | `TWI = ln(a/tanβ)` |
| **HYDRUS** | 物理土壤水（偏微分方程） | Richards `∂θ/∂t=∂/∂z[K(∂h/∂z+1)]` |
| **Farquhar** | 叶片光合双限制 | `A = min(Ac, Aj) − Rd` |
| **LPJ / CLM** | 动态植被 / 陆面集大成 | 能量平衡 `Rn = H + LE + G`；快慢过程耦合 |

> 核心张力：**倾倒水桶（概念、稳、参数易得） vs Richards 方程（物理、慢、易数值发散，须满足 CFL `Δt≤Δz²/2D`）**

### Round 5 动力系统 + 临界转变　难度：中级
| 模型 | 招牌机制 | 招牌式 |
|---|---|---|
| **Lotka–Volterra** | 捕食者-猎物振荡 | `dx/dt=αx−βxy`，`dy/dt=δxy−γy` |
| **SIR** | 传染病阈值 | `R0=β/γ`；群体免疫阈值 `=1−1/R0` |
| **Scheffer 浅湖** | 折叠分岔 + 迟滞 | 清/浊双稳态；去程阈值 > 回程阈值 |

**判别真突变 vs bug 三步**：① 对应物理阈值？② 步长减半仍在？③ 守恒？　｜　早期预警：临界慢化 → **自相关↑、方差↑、闪烁**　｜　铁律：线性库模型只有唯一稳态，多稳态必来自非线性。

### Round 6 数据驱动 + 混合 + 不确定性　难度：中→高
| 模型 | 招牌机制 | 招牌式 / 要点 |
|---|---|---|
| **Random Forest / XGBoost** | 集成树，抓非线性/交互 | 分布内强、**外推会卡住** |
| **GP 仿真器** | 慢模型的"快替身" | 预测自带均值 ± 方差（诚实给不确定性） |
| **KGML** | 知识引导 ML | 把守恒/物理写进损失，机理生成合成数据预训练 |

**打分**：`RMSE`↓ ｜ `NSE=1−Σ(o−s)²/Σ(o−ō)²` ｜ `KGE=1−√[(r−1)²+(β−1)²+(γ−1)²]`（均值预测基准 ≈ −0.41，非 0）

## 关键公式速查（跨轮通用）

| 名称 | 公式 |
|---|---|
| 一阶衰减 / 指数解 | `dC/dt=−kC` → `C(t)=C₀e^(−kt)`，周转 ≈ 1/k |
| 乘性限制因子 | `实际速率 = 潜在 · f(T)·f(W)·f(N)`（任一因子→0 则停） |
| 显式 Euler | `C(t+Δt)=C(t)+Δt·(dC/dt)` |
| Michaelis–Menten | `V=Vmax·S/(Km+S)`（S≪Km→一阶；S≫Km→零阶饱和） |
| Beer–Lambert 截光 | `I=I₀·e^(−k·LAI)`；截获 `=1−e^(−k·LAI)` |
| RUE 生物量 | `ΔDM=RUE·(1−e^(−k·LAI))·PAR` |
| GDD 热时间 | `max((Tmax+Tmin)/2−Tbase, 0)` |
| SCS-CN 产流 | `Q=(P−0.2S)²/(P+0.8S)`，`S=25400/CN−254` |
| Farquhar 净光合 | `A=min(Ac, Aj)−Rd` |
| 能量平衡 | `Rn=H+LE+G` |
| Nernst（DNDC） | `Eh=E0+(RT/nF)·ln([ox]/[red])` |
| CFL 稳定性 | `Δt ≤ Δz²/(2D)`（显式扩散格式） |
| 贝叶斯标定 | `p(θ|D) ∝ p(D|θ)·p(θ)` |
| SIR 阈值 | `R0=β/γ`，群体免疫 `=1−1/R0` |
| 鞍结分岔正规形 | `dx/dt=r−x²`（临界点典范） |
