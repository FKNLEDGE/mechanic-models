> 贯穿全程的一句话：**用代码做苦力，用农学做灵魂。**

---

## 这份指南是给谁的

如果你是农学 / 生态背景，会用模型却把它当"黑箱"——数据丢进去、结果吐出来，不知道里面在算什么——这份指南就是带你**把黑箱拆开**，看清并最终自己动手：模型用什么**公式**、计算机怎么**算**、怎么变成**软件**、怎么**校准参数 / 量化不确定性 / 做成可复现的论文**。

默认你**没有**数学或编程基础。每个概念都先打比方（浴缸水管、收音机旋钮、老师傅带徒弟、翻船、做一道能进菜谱的菜），再给能跟着算的小例子，最后才出现公式。

## 7 个思维框架（贯穿所有模型的骨架）

1. **状态变量 + 通量**（守恒律 / "浴缸"）——今天的量 = 昨天 + 进 − 出。
2. **多重限制因子**（潜在 × 胁迫 `f(T)·f(W)·f(N)`）——先算理想上限，再用 0–1 折扣往下打。
3. **速率 - 状态 - 更新**（显式 Euler）——一天一天往前"挪"，不是解方程。
4. **尺度层级**（点 → 田 → 区域 → 全球）——小尺度成立的关系大尺度未必成立。
5. **动力系统稳定性**（平衡、反馈、分岔、迟滞）——为什么系统会突然"翻车"。
6. **校准 - 验证 - 不确定性**（equifinality、Bayesian/GLUE）——给概率范围，不给假精确单点。
7. **机理 vs 经验 vs 混合**——什么时候用道理、什么时候用数据、什么时候融合。
