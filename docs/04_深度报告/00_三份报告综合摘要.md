## 报告一 · 计算内核与软件架构

### 1.1 共享的计算骨架
所有这类模型共用同一套结构:
- **状态方程(骨架)**:质量守恒 `dC/dt = Input − Output`。
- **反应动力学(血肉)**:一阶动力学 `Output = k·C`,孤立衰减为指数衰减 `C(t)=C₀·e^(−kt)`,周转时间约 `1/k`。
- **环境修正(灵魂)**:乘性限制因子框架 `实际速率 = 潜在速率 · f(T)·f(W)·f(底物)·…`,每个 f 归一化到 [0,1]。
- 综合形式:`dC/dt = Input − [ k·C·f(T)·f(W) ]`。

### 1.2 生物地球化学模型:多库一阶衰减级联

**RothC(最佳入门范例)**:5 个库 DPM、RPM、BIO、HUM、IOM。
- 年分解速率常数:**k_DPM=10、k_RPM=0.3、k_BIO=0.66、k_HUM=0.02 yr⁻¹**;IOM 惰性不变。月时间步。
- 官方算例(综合修正因子 abc=0.3561,Δt=1/12):DPM **0.1533→0.1140**、RPM **4.4852→4.4455**、BIO **0.6671→0.6542**、HUM **25.8576→25.8423**。
- 产物去向:DPM/RPM 分解为 CO₂ + BIO + HUM;CO₂ 与 (BIO+HUM) 的比例由黏粒含量决定;(BIO+HUM) 按 **BIO:HUM = 0.46:0.54** 拆分。
- IOM 初始化(Falloon et al. 1998):**IOM = 0.049·SOC^1.139**。

**CENTURY**:凋落物按木质素/氮比分到结构库/代谢库,SOM 分 active/slow/passive 三库。周转时间:active **数月到数年**、slow **20–50 年**、passive **400–2000 年**。土壤质地影响 active 周转(砂质更快)与稳定化效率(黏质更高)。C:N 随矿质氮线性变化(active 15→3、slow 20→12、passive 10→7)。

**APSIM-SoilN**:SOM 分 BIOM、HUM、可选 INERT;新鲜有机质 FOM 分 FPOOL1(碳水化合物,默认 0.2)、FPOOL2(纤维素,0.7)、FPOOL3(木质素,0.1)。

**DNDC 分解方程(Eq.3)**:`dC/dt = CNR·μ·(S·kₗ + (1−S)·kᵣ)·[C]`。SDR 值(1/day):很易/易分解凋落物 0.074、0.074,抗分解凋落物 0.02,易/抗分解微生物 0.33、0.04,易/抗分解腐殖质 0.16、0.006。

### 1.3 DNDC 的氧化还原核心:Nernst + Michaelis–Menten + 厌氧气球
- **Nernst(Eq.1,v9.5 印刷形式)**:`Eh = E0 + (RT/nF)·ln([oxidant]/[reductant])`,R=8.314 J/mol/K,T=273+t,n=转移电子数,F=96485 C/mol。
- **双底物 M–M(Eq.2)**:`F[oxidant] = a·[DOC/(b+DOC)]·[oxidant/(c+oxidant)]`。
- **厌氧气球**:两方程共有 [oxidant] 因子,用它定义土壤厌氧体积分数(0=全好氧,1=全厌氧),把底物分配到好氧/厌氧微域。还原序列依吉布斯自由能:**O₂ → NO₃⁻ → Mn⁴⁺ → Fe³⁺ → SO₄²⁻ → CO₂(产甲烷)**。
- 土壤物理:分层有限差分解热(傅里叶)与水(达西)通量;相对导水率 `K/K_sat = θ^(2β+3)`。

### 1.4 作物生长模型的核心方程
- **物候/热时间**:`GDD = max((Tmax+Tmin)/2 − Tbase, 0)`,Tbase 冷季约 5°C、暖季约 10°C。
- **辐射截获(Beer–Lambert)**:`I = I₀·exp(−k·LAI)`,截获比例 `1−exp(−k·LAI)`。
- **生物量(RUE,Monteith 范式)**:`ΔDM = RUE·(1−exp(−k·LAI))·PAR`。Monteith(1977)原文:约 **1.4 g/MJ**(对太阳总辐射,等效 2.4% 效率)。
- **土壤水两条路线**:tipping-bucket 级联(Ritchie 1998,用 LL/DUL/SAT/SWCON,稳定且参数易得) vs 数值解 Richards 方程(APSIM-SWIM,更机理但更慢)。
- **水分胁迫**:`SWFAC = 实际蒸腾 / 潜在 Ep`(0–1)。

### 1.5 数值方法
- **显式(前向)Euler + 固定日步是绝对主流**:`C(t+Δt) = C(t) + Δt·(dC/dt)|_t`。FSE、PCSE、CropSyst、DSSAT、APSIM 全部默认如此(实现简单、与日尺度天气匹配、对一阶衰减稳定)。
- **亚日步 + 算子分裂(operator splitting)**:DNDC 对厌氧气球/反硝化用小时步,把分解→硝化→反硝化→发酵按顺序依次求解。
- **空间离散**:土壤剖面分层(约 10 层),层间通量用有限差分。
- **初始化**:慢碳库需 spin-up(预热运行数百至上万年到稳态)。

### 1.6 软件架构(怎么搭成产品)
- **DSSAT-CSM**:Fortran 开源。所有作物共用一套代码 + 一个土壤模块。模块沿学科分界,仅通过接口变量通信,可即插即拔。每个模块六步操作循环:① run初始化 ② season初始化 ③ **速率计算** ④ **积分** ⑤ 日输出 ⑥ 汇总输出。文件生态:FileX、*.WTH、*.SOL、*.CUL/*.ECO。
- **APSIM Classic**:多语言 + 通用建模协议(CMP)消息引擎,"轮毂与辐条"架构,模块插拔。
- **APSIM Next Gen**:C#/.NET 完全重写。模型即内存中的组件树(基类 `Model`,含 Name/Parent/Children);.apsimx 是该树的 JSON 序列化;依赖注入用 `[Link]` 特性 + 运行时反射;事件用 .NET 事件 + `[EventSubscribe]`,`Clock` 逐日按固定顺序发布事件(体现"潜在→仲裁→实际→更新")。植物建模框架(PMF)所有函数实现 `IFunction` 接口,作物模型可在 GUI 中由通用 Function/Organ 组合而成。GUI 用 MVP 模式。
- **DNDC**:历史上是 Windows 平台 C++/VB 桌面应用(李长生 1992 首发,UNH 维护)。

### 1.7 全链路位置 + 你的生态位
非线性(M–M 饱和、乘性因子、阈值触发)使迭代模拟能产生突变/临界点。农学家的战场在两端:**定义机理**(改 f(T)、f(W)、过程方程)与**解释涌现**(识别临界点而非误判为代码 bug);软件/数值层(步长、积分法、并行)是工程师的战场。模块化设计的意义就是让这两层解耦。

**复现建议**:RothC → 修正函数库 → 最小作物模型 → DNDC 厌氧气球。

## 报告二 · 可运行代码 · 率定 · 混合ML · 突变动力学

### 2.1 分阶段可运行代码 + 测试基线
- **STAGE 1 RothC(Python)**:温度修正 `a = 47.91/(1+exp(106.06/(T+18.27)))`;水分修正 b(基于累积 TSMD,**最小 0.2**);覆盖修正 c(**有植被 0.6、裸地 1.0**);黏粒分配 `x = 1.67·(1.85+1.60·exp(−0.0786·%clay))`,`CO2/(BIO+HUM)=x`,`BIO:HUM=0.46:0.54`;`IOM=0.049·SOC^1.139`。进入碳 DPM/RPM 默认 **1.44**(59%/41%)。单元测试复现官方四个数到 1e-4。
- **STAGE 2 修正函数库**:Q10、Arrhenius、三基点 beta 函数、WFPS 钟形曲线,做成可互换函数。
- **STAGE 3 最小作物模型**:GDD 物候 + Beer-Lambert + RUE + SWFAC + tipping-bucket 土壤水。
- **STAGE 4 DNDC 厌氧气球**:Nernst + M–M + 小时步 + 算子分裂。参数:Kc=0.017 kg C/m³、Kn=0.083;最大生长率 GR_NO3,max=GR_NO2,max=**0.67 h⁻¹**、GR_NO,max=GR_N2O,max=**0.34 h⁻¹**;反硝化菌 C/N=**3.45**;D_air=**0.07236 m²/h**。Eh 阈值:反硝化 ≤ **500 mV**、产甲烷 < **−150 mV**;甲烷氧化 `CH4ox = CH4·exp(8.6711·Eh/1000)`。

### 2.2 五类数值陷阱的检测与修复
| 陷阱 | 检测 | 修复 |
|---|---|---|
| (a) 质量不守恒 | 库和 + 累积CO₂ + 淋失 = 初始 + 输入 | 查重复/漏算通量 |
| (b) 步长不收敛 | Δt 减半看解是否变 | 减小步长 |
| (c) 刚性发散/振荡 | 违反 **CFL: Δt ≤ Δz²/(2D)** | 小时步/算子分裂/隐式法;tipping-bucket 不解扩散方程故不受此约束 |
| (d) 负库 | `C−k·C·Δt<0` | 用解析解 `C·exp(−kΔt)`(恒正);切忌 `max(C,0)`(破坏守恒) |
| (e) spin-up 未平衡 | 监控慢库年际变化率 | 跑 3–5τ(τ=1/最小特征值)或解析稳态初始化 |

### 2.3 参数率定实战
- **敏感性分析**:Morris(初等效应 μ*、σ,廉价**筛选**)→ Sobol(一阶 S_i、总效应 STi,精确**量化**;STi≫Si 说明强交互)。工具 SALib(sample→运行→analyze)。
- **频率派**:PEST/PEST++,Gauss-Marquardt-Levenberg 算法 `(JᵀQJ + λ·I)·Δp = JᵀQ·(obs − sim)`,Jacobian 有限差分,Tikhonov 正则化,模型无关(.tpl/.ins/.pst 三文件)。DSSAT 内置 GLUE/GenCalc/GLUEP;R 包 CroptimizR。
- **贝叶斯 + MCMC**:`p(θ|D) ∝ p(D|θ)·p(θ)`。Metropolis-Hastings → DREAM(ZS)(水文/生物地球化学主力)、emcee(仿射不变 ensemble)、NUTS/HMC(PyMC/Stan)。等效性(equifinality)+ GLUE:后验分布远胜单点;强相关参数对不可辨识。
- **目标函数**:RMSE、NSE(=1−Σ(obs−sim)²/Σ(obs−mean)²)、**KGE = 1−√[(r−1)²+(β−1)²+(γ−1)²]**(r 相关、β 偏差比、γ 变率比)。注意:均值预测时 **KGE = 1−√2 ≈ −0.41**(而非 0)。多目标 → Pareto 前沿 → NSGA-II。

### 2.4 机理 × 机器学习混合建模
- **PINN**(Raissi et al. 2019, *J. Comput. Phys.* 378):把微分方程残差放进损失函数,可正解也可反演参数。
- **KGML / 知识引导 ML**(Karpatne, Kumar et al. 2017):把守恒律等科学知识注入 ML(损失惩罚/结构/预训练)。
- **仿真器/代理(emulator)**:用 GP/NN 仿真慢过程模型(GP 天然给均值+方差),回报最高、最易上手。
- **残差建模**:ML 学过程模型的误差 `corrected = model + ML(features)`,保留可解释性。
- **可微分建模**(Shen et al. 2023):整模型用 PyTorch/JAX 重写,梯度可由 AD/伴随法计算。Feng et al. 2022 的可微分 HBV(δ models)在 671 个美国流域中位 NSE **0.732**,逼近纯 LSTM 的 **0.748**(Daymet 驱动)。Neural ODE 是其重要形式。
- **旗舰案例 KGML-ag**(Liu et al. 2022, *GMD* 15:2839):GRU 骨架 + 中间变量初值 + 多任务 + 用 ecosys 合成数据预训练。交叉验证 N₂O 通量 **r²=0.81、RMSE=3.6 mgN m⁻² d⁻¹**,稳定优于纯过程模型与纯 ML。
- **取舍**:可解释性(残差/参数化 > 仿真器 > 纯ML);外推(保留机理骨架更稳);数据需求(KGML 用合成数据预训练降低观测需求)。
- **原型路线**:仿真器 → 残差建模 → 参数化替换/可微分。

### 2.5 临界点 / 突变 / 复杂系统动力学
- **动力系统基础**:不动点 f(x\*)=0;稳定性看 Jacobian 特征值实部(全部 <0 → 稳定;一维 f'(x\*)<0);吸引子、吸引域、相图。线性库模型 `dC/dt=I−ξkC` 唯一稳定平衡 `C*=I/(ξk)`;微生物显式模型可不稳定/振荡(*Biogeosciences* 2024)。
- **分岔理论**:鞍结/fold(`dx/dt=r−x²`,临界点典范)、跨临界(`rx−x²`)、叉式(`rx−x³`)、Hopf(振荡起源)。迟滞/多稳态:Scheffer 浅湖富营养化模型(清水/浊水两稳态 + 折叠灾变迟滞回线)。
- **临界慢化 + 早期预警信号(EWS)**:接近 fold 时主导特征值趋零,恢复变慢 → **滞后-1 自相关上升、方差上升、偏度变化、闪烁**。Scheffer et al. 2009 *Nature* 461;Dakos et al.;R 包 earlywarnings(`generic_ews`)。
- **与农业生态模型关联**:DNDC 的 Eh 阈值(500 mV / −150 mV)是阈值切换;土壤碳多稳态(Clayton et al. 2021 报告 **1% SOC** 处微生物化学计量突变);作物物候 GDD 阈值切换。**突变真伪三步判别**:① 对应物理阈值;② 步长收敛稳定;③ 质量守恒——三者皆满足才是真实 regime shift,否则是数值伪迹。线性库模型不会自发多稳态(若出现则是 bug)。

## 报告三 · 模型构建全链路(从想法到可复现已发表产品)

### 3.1 全生命周期七阶段 + 贯穿范例
**贯穿范例**:在华北平原冬小麦-夏玉米轮作中改进 DNDC 的水分胁迫函数 f(W),以更好模拟极端降雨下的 N₂O 峰值,贝叶斯标定、多站点多年验证、区域升尺度、作为 GMD 式模型发展论文发表。

- **Stage 1 问题表述**:五类可发表缺口(结构缺陷/未检验机制/未建模区域作物管理/模型互比/敏感性不确定性缺口)。翻译链:perceptual→conceptual→mathematical→numerical→code。Jakeman, Letcher & Norton 2006 的"十个迭代步骤"是良好建模实践骨架。
- **Stage 2 选型**:现成 vs 改造 vs 新建;"中等复杂度模型"原则(复杂度匹配数据可识别性 + Occam)。范例选"改造"(在 balloon 框架内换 f(W))。
- **Stage 3 数据**:驱动/标定/验证数据;FAIR 原则(Wilkinson et al. 2016, *Sci. Data* 3:160018);ICASA v2.0(White et al. 2013);AgMIP ACE/ACMO;QA/QC + gap-filling。
- **Stage 4 标定→验证→评价**:
  - **Klemeš 1986 分层方案**:分样检验(SST)→ 差异分样检验(DSST,在气候对比时段交叉标定验证,强迫外推到未见条件)。
  - **Gauch et al. 2003 MSD 三分解**:`MSD = SB + NU + LC`(系统偏差/非单位斜率/缺乏相关);SB 或 NU 主导→结构问题,LC 主导→不精确。
  - **Bellocchi et al. 2010** 综述:RMSE、EF(=NSE)、Willmott d。
  - **Wallach et al. 2021 "标定的混沌"**:法国小麦 **27 个组**、澳洲 **28 个组**(其中 **25 组同时参与**,M1–M29),即使同一结构,估计参数从 **2 到 10 个**不等(15 组估春化、13 组估光周期)。说明模型结构不完全决定精度。
  - **Wallach et al. 2024** 统一标定协议(*EMS* 180:106147)。
  - 区分 calibration / validation / evaluation。
- **Stage 5 不确定性量化与传播**:分类(输入/参数/结构/观测);前向传播——蒙特卡洛、FOSM(一阶)、**多项式混沌 PCE**(`Y ≈ Σ cₐΨₐ(ξ)`,高斯→Hermite、均匀→Legendre,可解析出 Sobol 指数);**多模型集合**——Asseng et al. 2013 *Nature Climate Change* 的 AgMIP 小麦 **27 个组**互比,充分标定后 **>50% 模拟产量落在 >300 个田间试验均值 CV(±13.5%)内**,集合中位数常优于单模型。
- **Stage 6 应用/情景**:气候影响、管理优化、区域网格运行。
- **Stage 7 发表与复现**:GMD 式模型描述论文 + 代码/数据可得性 + 基准测试。

### 3.2 升尺度(point→field→region→global)
- **支撑变化问题(change-of-support)**:点尺度标定的关系在聚合尺度未必成立。
- **基础设施**:pSIMS(Elliott et al. 2014, *EMS* 62:509–516)、并行网格 DSSAT-CSM(Alderman 2021, *GMD* 14:6541–6569,MPI+NetCDF)、GGCMI(Müller et al. 2019 *Sci. Data* 6:50;Franke et al. 2020 协议化参数扫描)。
- **聚合误差证据**:Hoffmann et al. 2016(*PLOS ONE*,14 个作物模型,德国 NRW,仅聚合土壤时误差 **<15%**);Hoffmann et al. 2018(100 km vs 1 km:Tuscany **20–30%**、NRW 冬小麦 **<15%**/青贮玉米 **<20%**,地中海个别达 **60%**)。

### 3.3 数据同化(DA,区别于标定)
- **标准 Kalman 分析步**:增益 `Kₜ = Pₜ|ₜ₋₁ Hᵀ (H Pₜ|ₜ₋₁ Hᵀ + R)⁻¹`;更新 `mₜ = mₜ|ₜ₋₁ + Kₜ(yₜ − H mₜ|ₜ₋₁)`。**H = 观测算子**,**R = 观测误差协方差**。
- **EnKF**(Evensen 1994;Burgers et al. 1998):用集合样本协方差替代 P,**必须扰动观测**(否则集合方差偏小)。强非线性下稳定、无需伴随。其他:EKF、粒子滤波、3D/4D-Var。
- **农业实例**:Sentinel-1(土壤水)+ Sentinel-2(LAI)联合同化进 WOFOST;Ines et al. 2013 把 MODIS LAI 同化进 DSSAT,R² 从 **0.47 → 0.51**。
- **DA vs 标定**:标定调时不变参数拟合历史;DA 在运行时反复更新时变状态。

### 3.4 耦合与多部门集成
- **耦合分级**:单向(offline) vs 双向(online);松耦合(文件/接口) vs 紧耦合(共享内存/直接调用)。
- **降尺度/偏差订正**:Delta 方法 `T_corrected = T_obs + (T̄_future,GCM − T̄_ref,GCM)`;分位数映射;动力降尺度(RCM,物理但昂贵)。
- **耦合基础设施**:BMI(Peckham et al. 2013;Hutton et al. 2020 *JOSS* 5:2317,标准函数 `initialize/update/get_value/set_value/finalize`)、OpenMI、OASIS3-MCT(**67 个组、80+ 应用**)、ESMF。
- **地球系统/经济耦合**:CLM 作物模块(源自 Agro-IBIS);LPJmL5 双向耦合进 GFDL CM2Mc(Drüke et al. 2021, *GMD* 14:4117–4141);经济侧 GLOBIOM、MAgPIE、IMPACT(已与 DSSAT 集成);AgMIP CGRA。
- **耦合数值问题**:不同时间步需算子分裂;界面须守恒;不同网格需保守重映射。

## 附录 D · 重要注意事项汇总(Caveats)

1. **DNDC Nernst 符号约定**:v9.5 印刷形式为 `Eh=E0+(RT/nF)·ln([ox]/[red])`,与许多教材的 `−(RT/nF)·ln([red]/[ox])` 符号相反、比值倒置,二者代数等价,实现时须与所参照版本一致。
2. **DNDC 厌氧气球的显式 anvf 公式与系数** 未印在 v9.5 PDF(该文档此点为概念性描述),来自代码级复现,系数无公开数值,生产用途须核实源码。版本(8.5/9.3/9.5)间可能有细微差异。
3. **RothC 官方算例** 只验证纯衰减项;完整模型还需加 (BIO+HUM) 回流、碳输入、IOM。
4. **CFL 稳定性界** 是线性扩散显式格式结果;tipping-bucket 不解扩散方程故不受此约束,但极端入渗下也可能非物理跳变。
5. **RUE 单位口径**:Monteith 的 1.4 g/MJ 对太阳总辐射;若 RUE 定义为对 PAR(约总辐射一半),数值约翻倍。务必核对口径,否则生物量差一倍。
6. **早期预警信号并非万无一失**:快速/强非线性强迫下自相关趋势可能不出现;方差上升也可能源于强迫本身变率。
7. **线性 vs 非线性多稳态**:RothC/CENTURY 线性库结构只有唯一平衡,不会自发多稳态(若出现则是 bug);多稳态须来自非线性微生物/CUE 反馈或外部驱动切换。
8. **KGE 基准** 为均值预测 ≈ −0.41(非 0);NSE 与 KGE 不可直接比较。
9. **评价指标分解之争**:Gauch 的 SB+NU+LC 与 Kobayashi/Theil 的 SB+SDSD+LCS 是不同方案,引用须注明版本。
10. **文献核查提醒**:报告三中提到的"harmonized calibration"框架,真实论文为 Seidel, Palosuo, Thorburn & Wallach 2018(*European Journal of Agronomy* 94:25–35),"协议"框架更贴合 Wallach et al. 2021/2024;部分阈值(如相对 RMSE<40%)为引用转述,按"据引"对待。
11. **聚合误差百分比**(NRW、Tuscany)来自特定区域案例,不可直接外推。
